# 已确认格式示例

本例只示范 15 秒单元的密度、时间线和末帧连续性。不得复制人物与台词。

## P01｜15秒｜身份露馅

【分镜】

人物站位：白天的男生宿舍，机位沿书桌与门口形成的轴线拍摄。江驰以长发少女外形坐在画面左侧电竞椅上，穿宽大的男士T恤，双腿交叠，双手横握手机；陆时衍站在画面右后方门口，右手端牛奶，正看向江驰。桌面没有可读文字，只有电脑风扇与手机游戏音效。

镜头1（0–5秒，中近景）：江驰拇指在屏幕上连续点按，身体跟着游戏节奏向前压，皱着眉冲手机骂：“打野你会不会？龙都不要？你在野区采灵芝呢？傻X！”最后一个字落下时把手机拍上桌面。

镜头2（5–9秒，门口过肩中景）：手机撞桌的声音还没散，江驰抬头看见门口的陆时衍。陆时衍没有走近，只把视线落向她仍交叠的双腿，平静开口：“江驰，把腿合上。”江驰嘴角一扯，头已经转回桌面：“合个屁，老子在自己寝——”

镜头3（9–13秒，江驰近景）：话音被她低头看见自己的身体截断。她刚才撑开的肩膀慢慢收住，双腿僵在原位，握手机的手停在桌边；眼睛从胸前移到宽大衣摆，呼吸卡住。

镜头4（13–15秒，双人中景）：江驰缓慢抬头看向陆时衍，嘴唇张开却只挤出一句：“……操。”陆时衍仍端着牛奶站在门口，眉眼没有变化。末帧停在两人的对视和江驰尚未合拢的双腿上。

【江驰声线】 20岁女性声线，中音偏低，音色明亮带一点沙哑；常态语速偏快、音量偏大、句尾利落，慌乱时起句卡住、尾音发虚，放松时恢复糙汉式直给；禁止夹子音、娇嗲和播音腔。

【陆时衍声线】 20岁男性声线，中低音，音色清冷干净；常态语速平稳偏慢、音量克制、句尾收得短，紧张时起句略迟但音量不抬高，放松后语气更低更简洁；禁止播音腔、霸总气泡音和夸张冷漠腔。
